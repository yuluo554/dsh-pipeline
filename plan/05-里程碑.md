# 里程碑与任务编排（plan/05）

> 原则：每周可演示；里程碑内任务标注【串行】（依赖既定口径）/【并行】（可派子 agent）。预计总时长 6-8 周（业余节奏），全速 3-4 周。

## M0 —— 仓库与 bundle 骨架（约 0.5 周）

目标：插件能被 dsh 装载，证明打包链路通。
- 【串行】仓库初始化（pnpm workspace 单包）、`package.json`（`dsh.bundle.patch` + `dsh.compatibility` + locale 元信息）、`cordis.patch.yml` 挂载行
- 【串行】hello 工具（照官方 tutorial 第 7 章模式）+ 最小测试脚本
- 【并行】`.gitignore`/LICENSE(MIT)/CI 空壳（lint+test）
- **演示物**：`dsh plugin add ./dsh-pipeline` → `--dump-config` 可见层 → agent 调用 hello 工具成功
- **DoD**：安装/卸载干净；卸载后工具消失（effect 语义验证）

## M1 —— 编译器 + runner + 入口（约 1.5 周）★核心

目标：#7704 主链路跑通。
- 【串行】`data/` fixtures + 快照真值冻结（plan/04）
- 【串行】schema.ts → ir.ts → compiler.ts（B1/B2 达标）
- 【串行】runner.ts（能力探测 + engine.start + 结果映射；能力 flag 探测方式按口径 4）
- 【串行】entry.ts：`/pipeline` 命令 + `pipeline` 工具
- 【并行】B3 mock engine 搭建与用例（接口冻结后即可开工，不等 runner 完成）
- **演示物**：`three-node-two-models.json` 真实跑通（大纲→复查→成文，两模型各自生效）
- **DoD**：B1-B3 全绿；演示录屏/日志留档；回写 plan/00、06，写 HANDOFF-M2

## M2 —— 护栏与失败策略（约 1 周）

- 【串行】取消传播验证（运行中取消 → 引擎中止受管进程 → runner 收 `cancelled`）
- 【串行】失败策略 abort/skip/retry 进编译器（B4）
- 【并行】错误信息本地化（locale/en+zh）
- **演示物**：注入坏节点，三种策略各演示一次；取消演示
- **DoD**：B4 全绿；失败路径测试含"引擎不可用/能力缺失降级"

## M3 —— Web 编辑器（约 2 周）

- 【串行】client 半骨架（`dsh.client` 声明 + client 构建 preset）
- 【串行】store RPC + 列表/表单编辑器（模型下拉读 catalog、技能读 `ctx.skills`、工具读 `ctx.tools`）
- 【并行】运行入口页（选流水线+输入+运行）
- **演示物**：零手写 JSON 配置并运行一条流水线
- **DoD**：编辑产物 `validateDef` 全过；与手写 JSON 双向一致；回写 plan + HANDOFF-M4

## M4 —— 运行视图 + 成本徽章（约 1.5 周）

- 【串行】`pipeline-run` ConversationNodeDefinition（节点链状态徽章，订阅 `workflow/*`）
- 【串行】每节点耗时/token 聚合（agent-start/end 时间差 + 会话统计）
- **演示物**：聊天中实时看到节点状态流转；双模型成本对比徽章
- **DoD**：事件断连/重连后卡片不脏渲染；回写 plan

## M5 —— 发布（约 1 周）

- 【串行】README（简介/特性/mermaid 架构/快速开始/评测表/限制/免责/已知环境问题）+ LICENSE
- 【串行】**干净环境验证**：新目录 clone + 全新 Node 环境（不依赖开发机全局包）按 README 逐条跑通；发现的问题修复并加回归测试
- 【串行】脱敏四步 + 历史三扫（留档 plan/RELEASE-M5.md）
- 【并行】npm 发包（预构建 lib/）→ 仓库打 `dsh-plugin` topic → awesome-dsh-plugin PR（标注回应 #7704）→ #7704 回帖 → dsh-market 提交
- **演示物**：GitHub 公开可访问；npm 可 `dsh plugin add`
- **DoD**：plan/00 验收门全部打勾；发布后复核 = GitHub 全新 clone 重跑全量测试

## 发布门速查（M5 逐条执行，命令与结论留档）

1. `git ls-files | grep -iE "\.env$|\.key$|secret|token"` 为空；.gitignore 覆盖运行产物/`data/**/_private/`
2. 内容级扫描全部跟踪文本：密钥赋值、手机号、身份证、个人路径 `C:\Users\xx`、内网 IP、邮箱（文档叙述里最爱藏个人路径）
3. 留档文档本身用占位符指代敏感字面值，不复述原文
4. 已推送才涉及历史重写 + force push + 终验三扫（`git rev-list --all` 逐提交 grep / `git log --all -p` 计数 / 提交信息扫描）
