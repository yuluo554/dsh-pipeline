# 需求解读（plan/01）

> 源材料：dsh-plugin-research/07-可行性报告（含 #7704 原文，存档 `ecosystem/disc-7704-full.txt`）。

## 痛点 → 能力转译表

| # | 用户痛点（#7704） | 转译为插件能力 |
|---|---|---|
| T1 | 重复任务要手动重复 4+ 轮对话配置，换模型/挂技能/贴提示词 | 流水线定义文件（可复用、可进 git）+ 一键运行 |
| T2 | 某轮忘记切模型或漏挂技能，容易出错 | 节点级显式声明 model/skills/tools，配置即代码，可审查 |
| T3 | 同一节点内需按序发多条提示词（计划→复查→设目标） | 节点内 `prompts[]` 有序数组，逐条投递并传递中间结果 |
| T4 | 上一节点输出要手动复制给下一节点 | 编译器自动把上游输出注入下游提示词（模板变量） |
| T5 | 各轮不在同一项目目录上作业不放心 | 所有子 agent 继承 parent 工作区（官方 subagent seam 原生行为） |
| T6 | 配置好了还想分享/迁移 | 定义为纯 JSON 文件，导入导出即复制文件 |

## 边界与非目标（防 scope 失控，动了要过 plan/06 决策记录）

1. **不做图形化拖拽画布**：表单式编辑器已满足 #7704；画布列 P3 观察项。
2. **不支持 ACP/Codex/Claude Code 后端的模型路由**：官方能力 flag 不支持，显式降级（FR-12），不做 workaround。
3. **不替代官方 `workflow` 工具 / agentTeams**：本插件是引擎的"专用消费方"，与两者共存。
4. **不内置任何模型 key / 不绑定 LLM 供应商**：模型列表读 dsh 自身 catalog；demo 用 DeepSeek 仅作示例。
5. **不做定时触发 / 入站唤醒**：与 proactive 类插件错位，防蔓延。
6. **兼容承诺**：只支持 `dsh.compatibility.dsh: ">=0.1.0-rc.5"` 锁定的 preview 线；不承诺 0.2+。
7. **单会话编排**：流水线在触发它的会话内运行（parent 绑定），不做跨会话/无人值守调度。

## 用户画像与成功指标

- 画像：dsh 重度用户 + 固定流程重复任务（办公自动化/内容生产/文档流水线）+ 成本敏感（这正是"每节点换模型"的动机）。
- 成功指标：M1 演示任务端到端成功；发布后 awesome 清单收录；#7704 作者确认使用；npm 周下载 > 50（观察项，不设硬门）。
